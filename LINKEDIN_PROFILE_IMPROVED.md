I design and ship production systems for transportation and logistics — from real-time dashboards to serverless microservices and 24/7 chatbots. **Key projects I built:**

• **Real-Time Control Center (Socket.io & Maps):** I designed the mission-critical dashboard that monitors hundreds of vehicles live. Achieved sub-second latency for immediate operational decisions. Migrated from Google Maps to Leaflet, integrated live routes, vehicle tooltips, and status indicators.

• **Mass Update Engine (RabbitMQ & AWS Lambda):** I solved the biggest operational bottleneck: Excel uploads with 50,000+ records. Built an async architecture that updates 5 transactional databases simultaneously — zero timeouts, full data integrity. Processing time dropped from 30 min to 8 min.

• **TraxiBot (Meta WhatsApp API + AI):** I developed a 24/7 virtual assistant for access self-service. Integrated 3 messaging providers (Baileys, Twilio, Meta WhatsApp). Used AI-assisted development to ship 60% faster — from architecture to deployment on AWS ECS.

• **Secure Access Ecosystem (Serverless):** I built a microservice (ZIP Lambda) that generates and encrypts 10,000+ passenger QRs in a single request. Optimized memory usage and security for batch operations.

• **Bustrax Integration (EventBridge):** I automated vehicle, route, and trip sync between two platforms. Eliminated manual data entry with scheduled sync every 5–30 min. Implemented shadow trip matching and multi-timezone support.

• **Bulk Operations (Web + Backend):** I implemented end-to-end bulk uploads for trips, passengers, vehicles, and routes — with progress tracking, validation, and status polling.

**Tech stack:** AWS (Lambda, S3, EventBridge, ECS), RabbitMQ, Node.js, TypeScript, PostgreSQL, MongoDB, Socket.io, React, Next.js, Material UI.
